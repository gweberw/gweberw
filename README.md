## `04 //` FEATURED_PROJECT

<div align="center">

### 🔎 Sistema de Auditoria de Fretes

Plataforma web para auditar fretes pagos por uma empresa: importa XMLs de **NF-e** e **CT-e** e verifica se o valor cobrado pela transportadora está de acordo com a cotação de frete registrada, comparando automaticamente cotação x cobrança real.

`Python 3.12+` `FastAPI` `SQLAlchemy` `Pydantic` `PostgreSQL` `Alembic` `Pytest` `React` `TypeScript` `Vite` `Docker`
